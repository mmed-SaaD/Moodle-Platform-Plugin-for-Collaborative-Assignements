**************************Soucis de nouveau role**********************************
Si le nouveau role (Responsible) ne s'affiche pas, il suffit de choisir <<Administration du site -> utilisateurs -> Definir des roles>>
On suite on choisit gestion des roles puis on coche les roles qu l'utilisateur peut voir.
Il se peut que dans quelque versions meme apres ces modifications, le nouveau role ne s'affichera que pour l'enseignant, donc pour regler ceci on suis ces etapes : 
1)_Securité
2)_Parametres de securité du site.
3)_Role visble du profile
Et on coche le nouveau role.
